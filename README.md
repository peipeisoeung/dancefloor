Dancefloor is just a fun little interactive webapp that allows you to customize the color of your frog by clicking on the tiles of the dancefloor.

I built this with the help of Claude-code.

I learnt so many new things about CSS: how to make the tiles interactive, and change the perspective of the dance floor.

This project inspired me to make the customization of each user's avatar/character on Choreographer more fun. There's just so much possibilities. 

I wanted to add some extra spotlight but struggled with that. Honestly, with a bit more time, I could probably figure it out.
